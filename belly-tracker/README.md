אפליקציה חסידית (עם הומור שחור על עצמי) למבצע הורדת השלייקס: מים, אוכל (קלוריות וחלבון), אימונים וריצות, והיקף מותניים/משקל לאורך זמן.

- גרסה חיה (שומרת בחשבון Claude, פרטית): https://claude.ai/artifact/25nxkv1mccRt9eqZmSGLfy
- `index.html` עובד גם לבד בדפדפן; אז הנתונים נשמרים רק בדפדפן (localStorage).
